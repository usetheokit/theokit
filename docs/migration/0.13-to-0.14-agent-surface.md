# Migration: 0.13 → 0.14 — the agent surface clean break

`theokit@0.14.0` **removes the pre-M2 proprietary agent surface** (`AgentEvent`,
`useAgentStream`, `defineAgentEndpoint`, `streamAgentRun`, `createConversationHistory`, the
client tool-cards). There is **no compatibility layer** — this is a hard break. The replacement
shipped in `theokit@0.13.0`: the zero-config `agents/*.ts` convention (`defineAgent`) served on
the ai-sdk `UIMessageStream` wire and consumed by `useAgent`.

This guide is the exact set of edits to move an app from the old surface to the new one.

## 1. Server: `defineAgentEndpoint` → `agents/<name>.ts` (`defineAgent`)

**Before** — `server/routes/chat.ts`:

```ts
import { z } from 'zod'
import {
  defineAgentEndpoint,
  streamAgentRun,
  createConversationHistory,
  type AgentEvent,
} from 'theokit/server'

export const POST = defineAgentEndpoint({
  async *handler({ body, request, cookieHeaders, signal }): AsyncGenerator<AgentEvent> {
    const { message = '' } = (body ?? {}) as { message?: string }
    try {
      const { agent } = await createConversationHistory({
        request,
        response: { headers: cookieHeaders },
        options: { model: { id: 'openai/gpt-4o-mini' } },
      })
      const run = await agent.send(message, { signal })
      yield* streamAgentRun(run)
    } catch (err) {
      yield { type: 'error', message: `Agent error: ${String(err)}` }
    }
  },
})
```

**After** — `agents/chat.ts` (a **top-level** file, sibling of `server/`):

```ts
import { defineAgent } from '@theokit/agents'
import { z } from 'zod'

export default defineAgent({
  input: z.object({ message: z.string() }),
  model: 'openai/gpt-4o-mini',
  system: 'You are a helpful assistant.',
})
```

TheoKit auto-serves this at `POST /api/agents/chat` (dev **and** build). No manual route, no
manual streaming, no conversation-history bookkeeping — `@theokit/sdk` owns the run + storage.
Provider resolution is unchanged (`OPENROUTER_API_KEY` / `ANTHROPIC_API_KEY` / `OPENAI_API_KEY`).

**Tools** still use `defineAgentTool` (from `theokit/server`) — pass them to `defineAgent({ tools })`.

## 2. Client: `useAgentStream` → `useAgent`

**Before**:

```tsx
import { useAgentStream } from 'theokit/client'

const { events, send, status, reset } = useAgentStream<{ message: string }>('/api/chat')
// events: AgentEvent[] — switch on event.type ('message' | 'tool_call' | 'tool_result' | 'error')
```

**After**:

```tsx
import { useAgent } from 'theokit/client'

const { messages, send, status, reset } = useAgent<{ message: string }>('/api/agents/chat')
// messages: UIMessage[] (ai-sdk) — render message.parts:
//   part.type === 'text'          → part.text
//   part.type === 'dynamic-tool'  → part.toolName / part.input / part.state / part.output
```

`send({ message })`, `status` (`'idle' | 'streaming' | 'done' | 'error'`), and `reset()` are
unchanged. The wire is now the ai-sdk `UIMessageStream`, so `@ai-sdk/react`'s `useChat` (or any
ai-sdk-compatible consumer) works against the same endpoint with no adapter.

## 3. Non-React / non-JS clients: `consumeAgentStream` → `consumeUIMessageStream`

```ts
import { consumeUIMessageStream } from 'theokit/client'

await consumeUIMessageStream(response, (message) => { /* message: UIMessage */ })
```

The endpoint speaks the standard `UIMessageStream` wire (`x-vercel-ai-ui-message-stream: v1`,
SSE `data: {json}` + `data: [DONE]`), so any ai-sdk reader (`readUIMessageStream`) consumes it.

## Removed exports (and their replacements)

| Removed (`theokit`) | Replacement |
|---|---|
| `useAgentStream`, `deriveLiveText`, `deriveError` (`theokit/client`) | `useAgent` (`theokit/client`) |
| `consumeAgentStream`, `parseSSEChunk`, `ConsumeOptions` (`theokit/client`) | `consumeUIMessageStream` (`theokit/client`) |
| `useAgentToolCards`, `foldAgentToolCards`, `defaultResolveEnvelope`, `AgentToolCard` (`theokit/client`) | derive tool cards from `message.parts` (`dynamic-tool` parts) |
| `AgentEvent` + variants (`theokit`, `theokit/client`, `theokit/core/contracts`) | `UIMessage` / `UIMessageChunk` from `ai` |
| `defineAgentEndpoint` (`theokit/server/define`) | `defineAgent` (`@theokit/agents`) in `agents/<name>.ts` |
| `streamAgentRun`, `createConversationHistory` (`theokit/server/agent`) | handled by `@theokit/sdk` inside the convention |
| the `theokit/server/agent` subpath export | (removed — its survivors are internal) |

**Unchanged / kept:** `defineAgentTool` (`theokit/server`), `provider-resolver`, the `@Agent`
class decorator (`@theokit/agents`, the advanced/DI surface), and the whole M2 surface
(`defineAgent`, `useAgent`, `consumeUIMessageStream`).

## Downstream

`@theokit/ui` consumers that imported `AgentEvent` from `theokit/client` migrate to the ai-sdk
`UIMessage` shape (same clean break; separate package). Pre-1.0 beta — no deprecation window.
