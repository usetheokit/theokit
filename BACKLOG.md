# BACKLOG — theokit

The single registry of maintenance work for this repository. One place to answer *"what is
pending in theokit?"*

`theokit` is an **autonomous scope**: it is its own repository, with no umbrella above it, so the
registry lives at its own root. Ids are monotonic, never reused and never renumbered — a killed
`B-007` stays `B-007` forever, because the number is the audit trail.

The schema, the status transitions, the verdicts and the five intake gates are defined once, in
[`.claude/rules/cycle-backlog.md`](.claude/rules/cycle-backlog.md). This file is data; that file
is the contract. Do not restate one in the other.

## How an item gets here

Two producers, one schema:

| Producer | Arrives as | Evidence at intake |
|---|---|---|
| `/backlog-item {slug}` — a human noticed something | `status: raw`, `source: human` | `none-yet` — deliberately. A hunch is a legitimate thing to record and an illegitimate thing to plan against |
| `/discover --sweep {domain}` — a measured finding | `status: triaged`, `source: discover-{mode}` | a pointer, attached by the measurement |

A sweep finding skips intake because it arrives with the evidence intake is not allowed to
require. Everything else passes gates G1–G5 in `cycle-backlog.md § Hard gates`.

Nothing reaches a plan without passing `/discover`'s measurement: `raw → planned` is forbidden.

## Domain routing

Derived from this project on 2026-08-19 by
`.claude/skills/backlog-init/scripts/detect_domains.py --root . --json` over `pnpm-workspace.yaml`
and `packages/*` — not copied from any inventory table. Scope: `single-repo`.

| Domain | Repos (present on disk) | Specialist |
|---|---|---|
| `theokit` | `theokit`, `packages/theo`, `packages/agents`, `packages/http`, `packages/presenter`, `packages/tauri`, `packages/create-theokit` | `.claude/agents/theokit.md` |

The bare `theokit` entry takes items about the repository itself — CI, release, root tooling, the
`.claude/` ecosystem. Code inside a published package is addressed by its path, so an item names
what it is about rather than the monorepo it sits in.

The authoritative copy of this table is
[`.claude/rules/cycle-backlog.md § Domain routing`](.claude/rules/cycle-backlog.md), which is what
`scripts/route_domain.py` parses when gate G1 runs. The copy here is a reader's convenience; if
the two disagree, the rule wins and this one is the bug.

**Excluded from routing, and said out loud rather than omitted:**

| Excluded | Reason |
|---|---|
| `examples/*` | pnpm-workspace members, but fixtures — a finding observed *through* an example is filed against the package it exercises |
| `my-test` | scratch output of `pnpm try:scaffold`, regenerated and deleted by `pnpm try:clean` |
