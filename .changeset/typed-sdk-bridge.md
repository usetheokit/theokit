The bridge event flow is typed end to end. \`translateSdkEvent\`, \`translateInteractionUpdate\`, \`createSdkAgentStream\`, \`realUsageDone\`, the think-tag and tool-dialect stream transforms and the agent endpoint produce \`AgentStreamEvent\` and need no casts; the variants are type aliases, so they stay assignable to the looser \`StreamEvent\`. \`SdkMessage\` is now the published \`SDKMessage\` union (run ids optional) instead of a string-indexed shape, and \`SdkTimelineEvent.update\` is an \`InteractionUpdate\`. \`SdkTurnHandle\` and \`SdkAgentHandle\` take the stream's element type: the default \`stream()\` yields \`AgentStreamEvent\`, and \`toAgentFactory\` returns \`SdkAgentHandle<SdkMessage>\`, which keeps the SDK vocabulary the ACP server needs. `toTypedAgentFactory` (and the `withTypedStream` adapter it uses) serve the same agent with `stream()` yielding `AgentStreamEvent`. \`DoneEvent\` declares the optional \`finishReason\` the reflective loop already read.

The event interfaces in `agent-stream-events.ts` are now type aliases (with one eslint-disable for the interface-preferring rule), and `DoneEvent` gains the optional `finishReason`. A typed stream of a guarded turn that ends without a terminal message gets a `done` built from the run outcome (result, usage), or an `error` when the run failed; a cancelled run ends its stream with no terminal event. `runAgentTurn`, the delegation port from an agent factory and the control session store read the SDK vocabulary, so they take `SdkAgentHandle<SdkMessage>`.

Add `toAgentStreamEvent` and `isAgentStreamEvent` to `@theokit/agents/bridge` to validate untrusted values as typed `AgentStreamEvent`s, plus `isThinking`, `isInputRequested`, `isMessageTimelineEvent` and `isDeltaTimelineEvent` narrowing helpers, so TheoClaw can consume the typed bridge contract without local declarations.

`SdkTurnOutcome` now carries `cost` and `error.code`. `SdkTurnHandle` stays lenient, with `stream` and `cancel` optional, so wait-only handles keep compiling. The strict contract is `SdkRun` (required `stream`, `events`, `cancel`, and a `status` that is always set) and `SdkRunAgent` (an agent whose `send` resolves an `SdkRun`). A real SDK `Run` and `SDKAgent` are assignable to them.
