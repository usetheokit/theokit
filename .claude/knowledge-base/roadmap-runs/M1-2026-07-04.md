# Milestone M1 — Eixo A — Canonical protocol (UIMessageStream)

## Objective (from ROADMAP.md)

Extend the bridge translator to emit all UIMessageStream part types (tool-call, tool-result, reasoning, error, finish) — not just text — validated by an E2E with useChat + assistant-ui rendering a tool-call card. Gate: an ADR deciding UIMessageStream vs AG-UI consciously.

## Definition of done (from ROADMAP.md)

- [x] `translateToUIMessageStream` emits tool-input-available / tool-output-available / tool-output-error + reasoning-start/delta/end + finish, via an open-block state machine.
- [x] A deterministic E2E asserts a tool part (input/output/state) + reasoning part through the real ai-sdk consumer (readUIMessageStream) — no live LLM, no custom adapter.
- [x] ADR 0036 records the canonical-protocol decision (keep UIMessageStream, reject AG-UI) with a re-eval trigger.
