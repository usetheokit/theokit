# Milestone M31 — Builder-only authoring API across all surfaces

## Outcome

The fluent builders (agent · tool · route · action · websocket · middleware · config · plugin) are the
ONLY public authoring surface. Every `define*` function + every `@theokit/agents` decorator (incl. the
`/decorators` subpath) removed from the public API (kept internal — each builder's `.build()` delegates).
Published breaking: `theokit@0.21.0` + `@theokit/agents@0.34.0`. Full suite 3898 green, canonical build
succeeds, anchor app `theo-code-v2` migrated + proven end-to-end. ADR-0043 + CHANGELOG migration guide.
Fixed a latent DTS-build `rootDir` issue (agents tsconfig `@theokit/http` source mapping) surfaced by
the un-export. PR #96 merged to main; tag v0.21.0.
