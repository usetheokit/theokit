# Milestone M4 — Eixo C — Cohesive harness (adapter over the SDK)

## Objective (from ROADMAP.md)

A cohesive harness (stateful loop, resume/approval, human-in-the-loop) packaged as an adapter/wiring
over `@theokit/sdk`, NOT a parallel runtime — gated by an accepted scope ADR before any code.

## Definition of done (from ROADMAP.md)

- [x] A scope ADR is accepted (ADR 0038) — the harness is an adapter, no parallel runtime.
- [x] `@HumanInTheLoop` pauses a gated tool (ai-sdk `tool-approval-request`; SDK `pre_tool_call` hook);
      `POST /api/agents/<name>/approve/<approvalId>` resolves it; deny/timeout continues.
- [x] `@Checkpoint({ storage: 'filesystem' })` emits `data-checkpoint` + resumes by `sessionId` via the
      SDK's durable store; non-durable storage warns (no false resume handle).
- [x] Reuses `@theokit/sdk` — no LLM call, no tool dispatch, no second loop (invariant guard test).
- [x] `examples/agent-saas` pattern + deterministic HITL E2E (pause → approve → run → done + deny + resume).

## Outcome

Shipped as an adapter over the SDK (ADR 0038). Multi-agent review found + fixed 2 HIGH (example client
approval reconstruction; @Checkpoint honesty) + MEDIUMs; cto re-review READY_TO_MERGE. Released via PR
#72 (feature) + #73 (Version Packages) → `theokit@0.15.0`, `@theokit/agents@0.30.0`.
