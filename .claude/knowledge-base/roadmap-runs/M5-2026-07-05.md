## Objective (from ROADMAP.md)

A terminal harness rendering stream + tool calls + approval of a local agent, reusing the M4 harness
(same adapter, different render surface).

## Definition of done (from ROADMAP.md)

- [x] A wedge decision is documented (ADR 0039) — terminal is a dev-time/local surface, not a CLI product.
- [x] `theokit agent <name> "<message>"` runs a scanned agent in the terminal: streaming text, tool

- [x] Reuses the M4 harness (`streamAgentUIMessages` + the in-process approval registry) — no new
      runtime (invariant guard test); zero new dependency.
