# Milestone M3 — Clean break — remove the proprietary surface + migration guide

## Objective (from ROADMAP.md)

Remove the old proprietary protocol/surface entirely; hard migration, no compat layer.

## Definition of done (from ROADMAP.md)

- [x] `grep -r "AgentEvent\|useAgentStream" packages/*/src` returns 0 (removed; replaced by the new surface).
- [x] A migration guide is published (`docs/migration/0.13-to-0.14-agent-surface.md`) covering `useAgentStream` → `useAgent` and `defineAgentEndpoint` → the `agents/*.ts` convention.
- [x] CHANGELOG marks BREAKING/Removed; examples + the default template migrated and green.

## Outcome

Delivered end-to-end through the full CYCLE (discover → plan → implement → code-quality →
review → release). Deleted the pre-M2 proprietary agent surface entirely (10 src files,
~1500 LoC): the `AgentEvent` SSE protocol, `defineAgentEndpoint`, `streamAgentRun`,
`createConversationHistory`, the `theokit/server/agent` subpath, and the client cluster
(`useAgentStream`, the AgentEvent SSE parser, the tool-cards). All superseded by the M2
`agents/*.ts` + `useAgent` surface, verified independent. The DoD gate
`grep -rE "AgentEvent|useAgentStream" packages/*/src` = 0 is enforced by an executable test.
Migrated the default template + fixture to `agents/chat.ts` (`defineAgent`) + `useAgent`
(deriving from `UIMessage.parts`); added `@theokit/agents` as a template dep; migrated 5 skill
docs + 26 tests; published the migration guide.

Two self-regressions were caught by the workspace typecheck + build gates and fixed (a stray
`AgentEvent` test importing a deleted module; a `tsup` entry for the deleted `server/agent/index`).
An independent adversarial review (2 rounds) found 2 BLOCKERs — the `create-theokit` package's OWN
test suite still asserted the old surface, and `package.json.tmpl` never declared the
`@theokit/agents` it now imports — both fixed + re-verified. Workspace typecheck 0 errors,
`theokit` build ESM+DTS green, no orphan exports. 80 M3-root + create-theokit 77 + @theokit/agents
559 tests green. The 32 remaining suite failures are all pre-existing + unrelated to agents.

**Version decision:** the changeset was authored `major` (Changesets would compute 1.0.0), but
per the ROADMAP 1.0 stability lock a pre-1.0 breaking change rides a MINOR bump — corrected to
`minor` → **theokit 0.14.0** after owner confirmation (1.0 is a deliberate milestone, not this
release).

Shipped via PR #70 (feature develop→main) → PR #71 (Version Packages, opened manually —
blocker #1). Published **theokit@0.14.0** manually (blocker #3: npm OIDC trusted-publisher 404 —
same as M0/M1/M2). The published `theokit@0.14.0` declares `@theokit/agents: ^0.29.0` (the
`workspace:^` converted correctly). `@theokit/agents` unaffected by M3.

Two release-infra blockers remain unresolved (issue #64, owner-only): Actions-cannot-open-PRs +
npm trusted-publisher binding.

Next eligible milestone: **M4 — Eixo C — Cohesive harness (adapter over the SDK)** — DoD-1 is a
scope ADR (GATE) accepted before any harness code.
