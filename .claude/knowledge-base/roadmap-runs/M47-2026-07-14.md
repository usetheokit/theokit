# Milestone M47 — `@Expose` decorator (visible, typed, surface-agnostic agent exposure)

## Objective (from ROADMAP.md)

An opt-in `@Expose` decorator binds a separately-built agent to a controller-style class making
route/auth/streaming visible in one code review; a typed, traceable handle (`useAgent(chat)`) kills the
magic string + duplicated input type; the same handle drives web/TUI/desktop from ONE declaration; `@Agent`
is reconciled so there is ONE exposure path, not a third.

## Definition of done

- [x] Design ADR accepted before code (ADR-0059 — opt-in, unifies @Agent, exposure-only, surface-agnostic).
- [x] `@Expose(agent)` ships in `@theokit/http`; the walker emits an agent-serving route; the dispatcher
      delegates to `mountAgent` via an injected `serveAgent` (http stays agent-runtime agnostic).
- [x] Typed client-safe handle in `@theo/agents` (`useAgent(chat)` — no magic string, no duplicated type).
- [x] The same handle drives web/TUI/desktop (`.inProcess()`/`.channel()` binders).
- [x] `@Agent` reconciled — a grep gate proves no parallel agent streamer (one runtime = mountAgent).
- [x] Showcase migrated to `@Expose` + `useAgent(chat)`; ADR + CHANGELOG + changeset + docs.
