# Milestone M0 — Walking skeleton

## Objective (from ROADMAP.md)

Prove the new architecture end-to-end on the thinnest slice — one agent file emitting `UIMessageStream` (text only), consumed by ai-sdk's `useChat` in a TheoKit app, one provider, one endpoint, one consumer.

## Definition of done (from ROADMAP.md)

- [x] A prototype agent surface emits `UIMessageStream` via the bridge (`translateToUIMessageStream`).
- [x] A TheoKit app consumes it with `@ai-sdk/react`'s `useChat` rendering streaming text without a custom adapter — proven by a green deterministic integration test.
- [x] The path is documented as the spine of the new architecture: request → SDK stream → bridge → `UIMessageStream` → SSE → `useChat`.

## Outcome

Delivered end-to-end through the full CYCLE (discover → plan → implement → code-quality → review → release). `@theokit/agents` gained `translateToUIMessageStream` (pure text-chunk mapping, errors surfaced as ai-sdk `error` chunk) and `theokit/server/define` gained `uiMessageStreamResponse` (SSE on the `x-vercel-ai-ui-message-stream: v1` wire). A deterministic integration test proves `useChat` parses the agent text with no custom adapter and no live LLM. Review found + fixed 1 BLOCKER (fixture body double-read) + 1 HIGH (Zod source-of-truth) + 3 MEDIUM before READY_TO_MERGE. Versioned via Changesets (`@theokit/agents` minor, `theokit` minor); shipped in the develop→main release PR #62. Additive/backward-compatible — the old `AgentEvent` SSE path is untouched (its removal is M3).
