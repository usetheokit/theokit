# Milestone M2 — Eixo B — Unified zero-config agent surface

## Objective (from ROADMAP.md)

A single zero-config convention `agents/*.ts` → SSE endpoint + generated typed client hook;
the dual path is resolved into one canonical surface.

## Definition of done (from ROADMAP.md)

- [x] `agents/<name>.ts` auto-generates the SSE route (file-based, like pages) — 1 file, 0 manual server wiring.
- [x] The client obtains a typed hook/binding from the agent route with no manual wiring (types inferred end-to-end from the server definition).
- [x] `@Agent` decorator and the file-based convention converge into ONE documented canonical surface; recorded in ADR 0037.

## Outcome

Delivered end-to-end through the full CYCLE (discover → plan → implement → code-quality →
review → release). `@theokit/agents` gains `defineAgent` — the canonical zero-config surface —
a pure normalizer that lowers to the same `CompiledAgentOptions` the `@Agent` decorator
produces, so both converge on one runtime (`@theokit/sdk`). The framework scans a top-level
`agents/` directory (LOCKED naming — sibling of `server/`), records agents in the manifest, and
auto-mounts `POST /api/agents/<name>` through a single shared `mountAgent` point at both
`theokit dev` and the built server (dev/prod parity). The endpoint streams the M0/M1 canonical
`UIMessageStream`; the client gets `useAgent('name')` typed end-to-end from the agent's Zod
schema via a generated `.theokit/agents.d.ts`, reusing `ai`'s own `readUIMessageStream` (no
reinvented parser). Agent endpoints enforce CSRF (a review-found HIGH) — a cross-origin POST is
rejected 403 before spending LLM tokens.

Two parallel independent reviewers (architecture + coverage) surfaced 1 HIGH security gap (no
CSRF), untested callers, and EC-2/EC-3 edges; all closed with tests. 49 M2 tests green (agents
12 + theo 37) incl. a built-server E2E through the real ai consumer; G1/G2 PASS; workspace
typecheck 0 errors.

Shipped via PR #68 (feature develop→main) → PR #69 (Version Packages changeset-release/main→main,
opened manually — blocker #1 Actions-cannot-open-PRs). Published `@theokit/agents@0.29.0` +
`theokit@0.13.0` **manually** (blocker #3: npm OIDC trusted-publisher 404 on PUT — same as M0/M1;
CI Release workflow failed at publish). The published `theokit@0.13.0` declares
`@theokit/agents: ^0.29.0` (the `workspace:^` converted correctly).

Two release-infra blockers remain unresolved (issue #64, owner-only): Actions-cannot-open-PRs
(repo setting) + npm trusted-publisher binding (npm dashboard). Both required manual intervention.
