# Milestone M35 — TUI terminal-only in-process surface (Model A)

Realize the TUI as a single-process surface — the TUI drives agent turns via the M33 in-process
caller with NO HTTP loopback, NO port, NO CSRF (the Claude Code / Codex single-process shape), while
keeping the HTTP client/server path (Model B) as a fallback.

closed on a gated agent without a resolver, function-form skills resolved for parity with mountAgent.
