# Milestone M46 — Conversation `thread` in the client core

## Objective (from ROADMAP.md)

React-free `theokit/client/core` store (history + in-flight + streaming→committed lifecycle + id
management), so web/desktop(Tauri)/TUI stop hand-rolling the transcript.

- [x] Per-turn `messages` unchanged (back-compat).
- [x] Web + TUI + desktop scaffold templates + showcase render `thread` (hand-rolled transcript deleted).
