## What shipped (M6)

The M6 live dogfood — a fresh `npx create-theokit` app streaming a real chat and running a
real `add` tool call (`137 + 456 → 593`) against `openai/gpt-4o-mini` via OpenRouter — caught and
fixed two real V1 bugs before the ship:

1. **Tool-call crash (`reading 'def'`).** `buildSdkTools` re-ran an already-lowered JSON-Schema
   `CustomTool` (from `defineAgentTool`) through the SDK's `defineTool` (which expects a live Zod
   schema). Now routes by `inputSchema` shape — Zod → `defineTool`; JSON-Schema `CustomTool` →
   forwarded raw. Locked by a regression test + a confirmed minimal repro.
2. **`@theokit/sdk` pin below the peer floor.** Default template + `template-default` fixture pinned
   `@theokit/sdk@^1.1.0`, missing the `./compaction` export `@theokit/agents@0.30.0` requires
   (`>= 2.13.0`) — a fresh scaffold failed to start (`ERR_PACKAGE_PATH_NOT_EXPORTED`). Bumped to
   `^2.13.0`. Default chat page now labels the real model (`gpt-4o-mini`); README version tables
   refreshed.
