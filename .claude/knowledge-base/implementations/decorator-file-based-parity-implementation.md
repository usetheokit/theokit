## T1.2 design resolution (SEPA pre-RED — [CRITICAL] reconciled, 95%-confidence)

The plan's "reuse `registerControllers` for the Web-Standard handler" is not literally
achievable: `registerControllers` returns metadata only (`{ verb, fullPath, walkResult }`);
the real dispatch (match + arg-bind + `@Body` validate + Response build) is private in
`packages/http/src/bridge/create-server.ts`. Resolution (same pattern as T1.1's
`transformControllerSource` extraction — honors ADR-1/Rule 9/G12):

1. **http:** extract `createDecoratorHandler(controllers): (request: Request) => Promise<Response | null>`
   from `create-server.ts` (returns `null` on no-match instead of a 404 Response, so the caller
   decides the miss). Refactor `createDecoratorServer` to wrap it (`res ?? 404`) — behavior preserved.
   Export from the barrel.
2. **theo:** `controller-dispatch.ts` = `scanControllers(dir, loadModule)` (load `*.controller.ts`
   via injected loader — `ssrLoadModule` in dev, `loadControllerWithSwc` in tests) →
   `createDecoratorHandler(classes)`; wrap a body-ful Web `Request` via **`incomingMessageToWebRequest`**
   (NOT the body-less `incomingMessageToHandlerRequest` — @Body needs the body); write `Response`→`res`.
3. **api-middleware.ts:345** — insert the controller attempt inside the `!match` arm BEFORE the 404
   (file-route-first precedence). Security headers + CORS + rate-limit + plugin `onRequest` already ran
   before the branch → inherited. **CSRF** runs inside `executeRoute`, so the controller branch applies
   the same CSRF gate for parity. `@Session()` is `undefined` in http dispatch (pre-existing http limit)
   — session param-binding is out of scope; parity claim scoped to security-headers/CORS/rate-limit/plugins/CSRF.
4. **Status contract (assert what is actually wired):** POST default **201**, bad `@Body` → **422**
   (`create-server.ts:184`), unmatched → fall through to the file-route 404.
5. **ADR-5:** `generateManifest` untouched — regression test asserts a routes-only fixture's manifest +
   `.theokit/client.d.ts` are byte-identical.
