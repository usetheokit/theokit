# TheoKit Decorator App

> Generated by `npx create-theokit my-app` — NestJS-style decorators on TheoKit

This is a complete TheoKit application using `@theokit/http-decorators` for
the backend API. It demonstrates the full developer experience:

## Project Structure

```
decorator-app/
├── server/
│   ├── controllers/        ← @Controller classes (your API)
│   │   ├── tasks.controller.ts
│   │   └── health.controller.ts
│   ├── services/           ← @Injectable services (business logic)
│   │   └── task.service.ts
│   ├── guards/             ← Guard classes (authentication)
│   │   └── auth.guard.ts
│   ├── dto/                ← DTOs with Zod schemas (validation)
│   │   └── create-task.dto.ts
│   └── main.ts             ← App bootstrap
├── app/                    ← Frontend (React pages)
│   └── page.tsx
├── theo.config.ts          ← TheoKit configuration
├── tsconfig.json           ← experimentalDecorators + emitDecoratorMetadata
└── package.json
```

## How it works

1. **Controllers** define HTTP endpoints with `@Controller`, `@Get`, `@Post`
2. **Services** contain business logic, injected via constructor DI
3. **Guards** protect endpoints with `@UseGuards`
4. **DTOs** validate request bodies with Zod schemas (`static schema`)
5. **TheoKit** mounts everything via `httpDecoratorsPlugin` in `theo.config.ts`
6. **Typed client** auto-generates `client.tasks.get()` on the frontend

## Quick Start

```bash
npx create-theokit my-app
cd my-app
pnpm install
pnpm dev
# Open http://localhost:3000
```

## API Endpoints

| Method | Path | Description | Auth |
|--------|------|-------------|------|
| GET | /tasks | List all tasks | - |
| GET | /tasks/search?q= | Search tasks | - |
| GET | /tasks/:id | Get task by ID | - |
| POST | /tasks | Create task | - |
| POST | /tasks/:id/complete | Mark as done | - |
| DELETE | /tasks/:id | Delete task | - |
| GET | /tasks/stats | Task statistics | Bearer token |
| GET | /health | Health check | - |

## Auth

Protected endpoints require `Authorization: Bearer theokit-token` header.

```bash
curl localhost:3000/tasks/stats -H "Authorization: Bearer theokit-token"
```
